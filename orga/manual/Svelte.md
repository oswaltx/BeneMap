package.json
- defines:
	- project name
	- scripts (npm run dev, npm run build)
	- dependencies (Svelte, [[Vite]], etc.)
	- Dev dependencies (build tools)
- it's like Gradle for the frontend (like build.gradle.kts)
- should never be edited manually -> is auto-generated by npm
svelte.config.js
- controls:
	- svelte compiler behavior
	- preprocessors
	- build options
- wont be touching this probably
tsconfig.json
- Defines TypeScript compiler settings
- Controls module resolution
- Strictness rules
tsconfig.app.json
- confugiration specifically for
	- brwoser code
	- svelte components
	- frontend runtime
- extends tsconfig.json
tsconfig.node.json
- configuration for
	- node envorionment
	- vite config
	- build tools
vite.config.ts
- controls
	- dev server behavior
	- plugins
	- build output folder
	- proxy configuration (if used)
- use cases
	- change dev port
	- configure backend [[proxy]]
	- modify build output directory
